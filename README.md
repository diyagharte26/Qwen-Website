# SysPilot — Intelligent Operations for Enterprise Infrastructure

A premium, enterprise-grade marketing website for SysPilot — an intelligent operations platform that brings together enterprise infrastructure expertise and AI-driven innovation.

![TypeScript](https://img.shields.io/badge/TypeScript-5.7-blue)
![Vite](https://img.shields.io/badge/Vite-6.3-purple)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-4.1-38bdf8)

## 🎯 Purpose

This is a **pre-launch enterprise demo website** designed to:

1. Build trust with enterprise decision-makers
2. Showcase SysPilot's capabilities without revealing implementation details
3. Drive qualified organizations toward demo requests
4. Establish credibility through OS3 and EvoMind organizational context

**Primary conversion goal:** Organization → Understand SysPilot → Build Trust → Request a Demo

## 🚀 Features

### Multi-Page Architecture
- **Home** — Platform overview, solutions, enterprise features
- **Company** — OS3, EvoMind, product ecosystem, trust principles
- **Resources** — Use cases, insights, product brief, demos

### Enterprise Design
- Deep black backgrounds with SUSE-inspired green accents
- Glassmorphism cards with subtle borders
- Sophisticated canvas animations
- Minimal, purposeful motion
- Premium typography (Space Grotesk + Inter)
- Large whitespace and clean hierarchy

### Content Strategy
- No agent names, counts, or specific metrics
- Focus on intelligence, automation, observability, governance
- Enterprise operations messaging
- Trust-building organizational context
- Professional, credible tone

## 🛠️ Tech Stack

- **Framework**: React 18.2 + TypeScript 5.7
- **Build Tool**: Vite 6.3
- **Styling**: Tailwind CSS 4.1
- **Animations**: Framer Motion 11.16
- **Routing**: React Router DOM 6.8
- **Icons**: Lucide React 0.294

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/syspilot-website.git
cd syspilot-website

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Content Rules

This is a **pre-launch enterprise demo website**. Therefore:

**DO NOT display:**
- Number of agents
- Agent names
- Agent catalogue
- MTTR percentages
- Number of customers
- Usage statistics
- Trial claims
- Pricing
- "Runs today" claims
- Execution counts
- Internal implementation details

**DO emphasize:**
- Intelligence
- Automation
- Observability
- Governance
- Enterprise Operations
- SAP
- Linux
- AI-powered Operations
